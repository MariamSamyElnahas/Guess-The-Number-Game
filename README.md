**Guess The Number Game** is an interactive number guessing game built using **HTML, CSS, and JavaScript**, with a UI inspired by the dark and mysterious atmosphere of **Stranger Things**.

The game generates a random number between **1 and 100**, and the player tries to guess it. After each guess, the game provides feedback:

* **Too Low** if the guessed number is smaller than the target.
* **Too High** if the guessed number is larger than the target.
* **Congratulations!** when the player guesses the correct number.

The game also includes a **guess history table** that records each attempt and its result, making it easy for the player to track their previous guesses.
